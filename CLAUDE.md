# Reglas para editar el inventario (index.html)

Este repositorio es un solo archivo, index.html. Si dos sesiones lo editan desde copias distintas, la ultima en subir borra los cambios de la otra (ya paso con el popup "Descargar de inventario").

1. Antes de editar, baja la ultima version de index.html desde GitHub (rama main). Nunca trabajes sobre una copia guardada de antes.
2. Haz el cambio sobre esa version.
3. Antes de subir, comprueba de nuevo que main no haya cambiado. Si cambio, baja otra vez y reaplica tu cambio.
4. Despues de subir, busca en el archivo publicado el texto orderImportScrim. Si no aparece, el popup "Descargar de inventario" se borro: restauralo antes de terminar.
5. Nunca subas el archivo completo reemplazando todo sin haber hecho los pasos 1 y 3.
